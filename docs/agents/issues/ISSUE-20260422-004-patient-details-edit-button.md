# Add an Edit/Add Patient Information button in patient details panel

## Request

When clicking a patient card and opening patient details, add a new button to edit/add patient information.

## UX requirements

- Place the new button at the bottom in the same action row as the existing button.
- Use a lighter blue style so it is visually distinguishable from the other existing action button.

## Expected outcome

- User can open patient details and quickly enter edit mode from this new button.
- Button hierarchy/contrast is clear and intentional.
