# Unit map should support mouse-wheel zoom

## Request

User should be able to zoom in/out of the unit map using the mouse wheel.

## Expected behavior

- Hovering over the map and using wheel zooms the map in/out smoothly.
- Zoom has sensible min/max bounds.
- Panning/drag interactions remain usable.
- Zoom state does not break card drag/drop, selection, or assignment actions.

## UX expectations

- Default zoom starts at 100%.
- Optional quick reset to 100% (button or shortcut).
- Zoom should feel responsive and not janky.
