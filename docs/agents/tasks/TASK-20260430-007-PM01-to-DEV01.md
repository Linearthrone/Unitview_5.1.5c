## Objective

Add a consistent **"+ Assign staff member"** action on all staff cards without an assigned person, wired to assign that card's **role and shift responsibilities**.

## Scope

Card types:
- Charge Nurse (`charge-nurse-card.tsx`)
- Unit Clerk (`unit-clerk-card.tsx`)
- Staff Nurse / Float Pool (`nurse-assignment-card.tsx`)
- Patient Care Tech (`patient-care-tech-card.tsx`)
- Any other role cards on the unit map

## Requirements

1. **Unassigned detection**
   - Treat as unassigned: `Unassigned`, empty/whitespace, and placeholder names (e.g. `New Staff Nurse`).

2. **Button**
   - Label: **`+ Assign staff member`** (consistent everywhere).
   - Prominent on card body when unassigned (not only context menu).

3. **Behavior**
   - Opens assign flow scoped to **this card** (role + responsibilities for the shift).
   - After assign: card shows staff name, spectra, and assignment slots as today.
   - Prefer existing `AssignStaffDialog` / `onAssignStaff` patterns; extend if card context is missing.

4. **013 coordination**
   - If redesign changes card layout, preserve this action in the redesigned component.

## Acceptance criteria

1. Every unassigned staff card type shows the button and successfully assigns staff.
2. Assigned card retains patient slots / PCT group / role duties for the shift.
3. Typecheck + build pass.
