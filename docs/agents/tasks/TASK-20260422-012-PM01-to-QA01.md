## Objective

Validate fixes for unit isolation, right-column drag behavior, and duplicate room rendering.

## Test matrix

1. **Cross-unit isolation**
   - Open Unit A and Unit B.
   - Make deliberate layout/data change in Unit A.
   - Verify Unit B remains unchanged.
   - Repeat inverse direction.

2. **Right-column room drag**
   - Unlock layout.
   - Drag each right-column room card to valid target cells.
   - Verify movement on screen and persistence after save/reload.

3. **Duplicate room check**
   - Inspect first row and right-column map region.
   - Confirm no duplicate of right-column rooms.

4. **Regression**
   - Basic save layout.
   - Switch between units.
   - Return and verify state integrity.
