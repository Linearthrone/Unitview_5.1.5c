2. **Shift assignment print layout GUI**
   - Build a user-facing GUI/editor for assignment print layout:

     - order sections,

   - Minimum configurable sections:
     - header/meta (date, shift, unit, charge),
     - nurse assignment blocks,
     - tech blocks,
     - unit stats/alerts,
     - legend.
   - Provide reset-to-default control.

3. **Persistence**
   - Save layout config per unit (or app-wide if unit-scope is not technically feasible this pass).

   - “Print using current layout” action must render from the saved/current config model.

5. **Backward compatibility**
   - If no config exists, current default layout must still print.
