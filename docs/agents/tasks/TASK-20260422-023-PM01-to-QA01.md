## Objective

Validate print reliability fixes and the new shift-assignment print layout GUI.

## Test matrix

1. **Base print reliability**
   - Print charge report.
   - Print shift assignments.
   - Validate output is generated and not blank/truncated.

2. **Layout configurator coverage**
   - Reorder sections and verify rendered print output follows new order.
   - Move sections between layout regions/columns and verify placement.
   - Toggle section visibility and verify inclusion/exclusion.
   - Reset-to-default and confirm default print layout restoration.

3. **Persistence**
   - Save custom layout.
   - Reload app / reopen unit.
   - Confirm layout settings persist and print output reflects saved config.

4. **Regression**
   - Confirm existing non-assignment print flow remains functional.
   - Smoke check that unit workflow is unaffected (no crashes from opening print UI).

## Acceptance criteria

- Shift print layout GUI is usable and accurate.
- Printed output matches configured order and placement.
- Saved layout persists correctly.
- No major regressions in charge print flow.
