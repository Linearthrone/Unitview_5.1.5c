# TASK-20260422-011 DEV-01 Completion Report

## Root cause summary

1. **Cross-unit contamination**
   - Root cause: room deletion path in `patientService.deletePatient()` scanned **all layouts** and removed by patient id from first match, instead of the currently active layout only.
   - Fix: changed deletion API to `deletePatient(layoutName, patientId)` and scoped deletion to `db.getPatients(layoutName)` only.

2. **Right-column room drag not moving**
   - Root cause: duplicate room id/bed setup in seeded map (`811` existed both in top row and right column), causing drag operations to target the wrong duplicated room record.
   - Fix: removed duplicate seeded top-row rightmost room value that conflicted with right-column seed.

3. **Duplicate right-column card on first row**
   - Root cause: same seed duplication (`811`) rendered once in first row and again in right column.
   - Fix: updated top-row seed list to avoid the duplicate entry.
