## Zoom range and fit algorithm

| Constant | Value |
|----------|--------|
| `MIN_ZOOM_FLOOR` | 0.2 (20%) |
| `MAX_ZOOM_CEILING` | 2.0 (200%) |
| `ZOOM_STEP` | 0.08 (8% per click) |

**Fit algorithm:** `measureFitZoom()` computes `min(availW/contentW, availH/contentH)` with 16px padding, clamped to floor/ceiling. Content size measured from grid `offsetWidth/offsetHeight`.

**Manual override:** `zoomIn` / `zoomOut` set `userAdjustedZoomRef.current = true`; reset via percentage click clears override.
