### 4. Right Spectra panel (§6)
- Map + Spectra side-by-side layout (`lg+`: map ~⅔, panel ~⅓).

- **Manage pool** button in panel header (role-gated).

- Device log view/add context menu items admin-only (§6.1.10).

### 5. TASK-20260430-007 — Assign staff member
