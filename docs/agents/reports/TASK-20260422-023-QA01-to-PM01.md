## Code verification — print pipeline files

### `renderer/src/lib/print-utils.ts`

- Shared `PRINT_REPORT_CSS` for assignment + charge targets.
- `openPrintWindow`: validates DOM target, handles popup blockers, escapes `</script`, try/catch with window close on failure.
- `openPrintWindowWithElectronFallback`: attempts `electronAPI.printToPDF` when available; falls back to browser print.

### `renderer/src/components/printable-assignments.tsx`

- Config-driven `sectionRenderers` map for all five required sections (`header`, `nurseBlocks`, `techBlocks`, `unitStats`, `legend`).
- Layout modes: single-column stack vs two-column main/sidebar.
- `previewMode` omits print target id (avoids duplicate `#printable-assignments-report` in dialog preview).

### `renderer/src/components/assignment-print-layout-dialog.tsx`

- Full editor: column mode, per-section enable/order/region, live preview pane, reset, save, print-from-draft.
- `sanitizeAssignmentPrintLayout` applied on draft mutations.

### `renderer/src/components/app-header.tsx`

- Print dropdown: Charge report, Assignments, Configure assignment layout… (when `onConfigureAssignmentPrint` provided).
- Wired from `unit-view-client.tsx` L1331–1332.

### Persistence layer

- Schema: `renderer/src/types/assignment-print-layout.ts` (version 1, sections, regions, sanitize/sort helpers).
- Service: `renderer/src/services/printLayoutService.ts` (get/save per layout name).
- Storage: `assignmentPrintLayout` on layout records in `database-simple.ts`.
