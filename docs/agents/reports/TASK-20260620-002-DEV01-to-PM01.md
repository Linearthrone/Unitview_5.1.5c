## Executive summary

Demo user **`wall` / `wall123`** with `appRole: 'WALLDISPLAY'` is seeded reliably via idempotent merge in `initializeAuth()`. Stale localStorage installs receive the missing `wall` user without wiping existing accounts. Password sync for all `defaultPasswords` entries runs every init.

## Migration algorithm (verified)

**File:** `renderer/src/services/authService.ts` — `initializeAuth()`

1. Load database via `getDb()`.
2. Build `Set` of existing `employeeNumber` values from stored users.
3. For each entry in `defaultUsers` (`renderer/src/types/auth.ts`): if `employeeNumber` not in set → `database.saveUser(user)` (additive only).
4. For each entry in `defaultPasswords`: if stored password differs from default → `database.savePassword(employeeNumber, password)`.
