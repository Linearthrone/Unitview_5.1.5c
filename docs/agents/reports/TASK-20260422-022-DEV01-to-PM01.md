## Status: Complete

## Summary

Stabilized the print pipeline (removed Tailwind CDN dependency, added error feedback) and delivered a GUI-driven shift-assignment print layout configurator with per-unit persistence, live preview, and config-driven rendering.

## Config schema

`AssignmentPrintLayoutConfig` (`renderer/src/types/assignment-print-layout.ts`):

| Field | Type | Purpose |
|-------|------|---------|
| `version` | `1` | Schema version |
| `columnMode` | `'two-column' \| 'single-column'` | Page layout |
| `sections[]` | `{ id, label, enabled, order, region }` | Section toggles, order, placement |

**Section IDs:** `header`, `nurseBlocks`, `techBlocks`, `unitStats`, `legend`

**Regions:** `full`, `main`, `sidebar`

Default config matches the previous hardcoded layout (two-column with stats + legend in sidebar).

## Known limitations

- Region placement is ignored in single-column mode (sections stack in order).
- Electron `printToPDF` is attempted when available but browser print remains the primary path.
- Charge report layout is not yet configurable (out of scope).
